# Neomarket — sitio de demostración

Concepto de sitio web para una automotora (marca ficticia **Neomarket**).
Autos nuevos y seminuevos, catálogo con filtros, ficha de vehículo, simulador de
crédito y tasación online.

## Stack

HTML + CSS + JavaScript en un solo archivo (`index.html`). Sin framework, sin
build. Fuentes desde Google Fonts y fotos desde Unsplash (CDN).

## Ver el sitio

- **En línea:** https://BENJAMIN.github.io/neomarket-demo/  _(reemplazar por el usuario real)_
- **Local:** abrir `index.html` con doble clic.

## Editar

Todo el contenido, estilos y lógica están en `index.html`. Los datos de los
vehículos están en el arreglo `VEHICULOS` dentro del `<script>`.

> Nota: `carmona/`, `_artifact/` y `_build/` quedan fuera del repositorio
> (ver `.gitignore`): son variantes y herramientas locales.
